# Archived Python Reference

`vikunja-cli.py.txt` is a frozen historical reference. It is not an executable,
supported fallback, and it will not receive fixes, features, compatibility
updates, security updates, or further tests.

Do not rename it back to `.py`, run it, configure an agent to use it, or use it
as a second tracker writer. Use the maintained TypeScript MCP instead:

```text
npm install -g vikunja-fastmcp@latest
```

`test_vikunja_cli.py.txt` and `requirements.txt` are retained only to preserve
the historical context of the archived reference. They are not part of the
supported product gate or npm package.

Report and fix product issues only in the maintained TypeScript MCP. Issues
that affect only these archived Python files are intentionally out of scope.
