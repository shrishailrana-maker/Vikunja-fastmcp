# Authors

The repository began as a fork used to evaluate an earlier Vikunja MCP
implementation. Vikunja FastMCP is now a **clean-room, v2-only rebuild**. All
prior code was removed and the project was rewritten from scratch against the
documented v2 API contract. No source or runtime code from the original fork
remains. The rebuild targets the Vikunja v2 REST API only and never falls back
to v1.
